## 📌 Notes

- **Load testing** validates expected performance under normal conditions; **stress testing** pushes past normal capacity to find the breaking point; **spike testing** checks how the system handles sudden traffic surges.
- When analysing JMeter results, focus on **response time, throughput, error rate**, and where the system starts to degrade.
- A strong CI pipeline should run automated tests on every push and fail the build on test failures, giving fast feedback to developers.
- Your QA portfolio should showcase real, complete artefacts — test plans, strategy docs, bug reports, automation scripts, API collections, and performance reports — as evidence of end-to-end QA capability.
