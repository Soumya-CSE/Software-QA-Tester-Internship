## 📌 Notes

- Bug reports should include: Summary, Steps to Reproduce, Expected vs Actual Result, Severity, Priority, Environment, and Attachments where relevant.
- Track each bug through its full lifecycle: **New → Open → In Progress → Fixed → Retest → Closed** (or **Reopened** if it fails retest).
