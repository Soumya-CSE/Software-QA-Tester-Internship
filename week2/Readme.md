## 🚀 MINI PROJECT — WEEK 2

### **End-to-End Testing of a Demo E-Commerce Website**

Complete the following activities:

1. Create a detailed **Test Plan**
2. Identify and log **15+ defects** in Jira
3. Assign appropriate **Severity & Priority** to each defect
4. Track defects through the complete life cycle:
   **New → Open → In Progress → Fixed → Retest → Closed**
5. Reopen defects that fail during retesting
6. Execute regression testing after bug fixes
7. Prepare a professional **Test Summary Report**

## 📌 BUG REPORTING CHECKLIST

Each bug report should contain:

* **Bug ID**
* **Summary / Title**
* **Module**
* **Steps to Reproduce**
* **Expected Result**
* **Actual Result**
* **Severity**
* **Priority**
* **Environment**
* **Browser / Device**
* **Attachments / Screenshots**
* **Bug Status**

## 🔄 BUG LIFE CYCLE

**New → Open → In Progress → Fixed → Retest → Closed**

If the defect fails during retesting:

**Retest → Reopened → In Progress → Fixed → Retest → Closed**
